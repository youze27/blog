# 学习计划暂存区

本文件夹存放**学习计划**和**未完成的学习步骤文档**。

## 流程

1. 制定计划时，由 skill 在本目录生成 `<主题>.md` 学习计划（操作说明书式）
2. 开始动手学习时，把文档移动到 `src/<对应分类>/`（分类规则见 skill 的 `references/blog-conventions.md`）
3. 学习过程中按文档补全截图、踩坑记录，最后补充面试知识点总结

## 说明

- 本目录不属于 `src/`，不会被 VuePress 构建，仅作内部暂存
- 移动文档时注意同步调整图片引用路径（改为 `assets/` 相对路径）与 frontmatter 的 date/order
