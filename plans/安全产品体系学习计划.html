安全产品体系学习计划（攻防一体版）

目标：作为网络安全从业者（安服工程师方向，攻防兼顾），通过"开源还原商业产品 + 渗透测试实战 + 攻防结合"，把主流安全产品每个核心功能和对应攻击技术都弄明白并实操。防御线补齐产品经验，攻击线把"会用工具"补成体系化方法论，达到"没用过商业设备也能展示等同使用经验"的成熟度，求职时攻防两端都有可展示项目。

结合昆明本地岗位画像（驻场安服 / 电力行业 / 应急响应 / 等保合规 / 蓝队值守为高频方向）与 GOAD 域控靶场，把"机器靶场 / 安全产品 / 攻防演练"串联成一条互相利用的链路：攻击打 GOAD 与靶站，检测看自家搭建的产品栈，日志回填规则。

纯 md 计划文件。文章标题 = 「工具/产品-实验内容」，标注 ★ 的为攻防结合篇（用攻击验证自家搭建的产品与规则）。

v2 改版说明（按资深安服视角精简）：原 58 必做篇偏"SOC 工程师 + 红队"，与安服/驻场目标不匹配。现精简为 34 必做——砍掉/降级 Security Onion 全栈、Kibana 大屏、Shuffle SOAR、OpenRASP 深度、ADCS 深度、Viper/Empire、AI 渗透双篇、Squid、Caldera 等，把省下的时间投入：Python 脚本线（多家 JD 明确要求）、应急响应多场景（Web/勒索挖矿/钓鱼 3 篇）、等保 2.0 实操（从"了解"升为"必做"）。

通用学习方法

  • 双线并行、攻防互为验证：防御线（安全产品）+ 攻击线（渗透测试）同步推进，用攻击检验自己搭的产品，用产品检测自己的攻击
  • 功能映射：每个商业产品 → 用顶尖开源/免费方案 1:1 还原核心功能来学
  • 一次搭建，层层叠加：同一套实验网络按阶段叠加，前阶段设备的日志被后阶段使用
  • 产品学习一律从部署开始：每款产品/工具的第一篇就是部署篇——环境准备 → 安装/镜像拉取 → 依赖与基础配置 → 验证服务真正跑起来（页面/端口/日志可见），部署不通过不进入下一步；之后的篇目才是功能配置、规则调优与攻防验证。每篇的操作说明书里，"部署"都是第一步标题
  • Python 贯穿始终：渗透脚本、日志解析、POC 编写、应急脚本统一用 Python 完成（不另起语言），脚本积累进个人工具库，求职时可展示
  • GOAD 专职内网靶场：GOAD（3域2林5台域机）只当"被打的一方"，被测产品当"看的一方"——攻击链打在 GOAD 上，自家 SIEM/EDR/Suricata 去检测，一次演练同时练红蓝双方
  • 每功能一验证：每个核心功能都要动手配一遍 + 截图 + 记录踩坑
  • 文档即项目：每篇文章就是一个项目，写博客沉淀，简历可直接引用

分层与实验策略

  • 必做：开源成熟 + 面试高频（含昆明岗位高频的基线核查、应急响应、内网/域渗透、等保合规），按"前置渗透基础 → 边界 → 资产 → 检测 → 管理闭环 → 内网纵深"逻辑推进；Python 线 + 应急响应多场景 + 等保 2.0 实操为 v2 新增重点
  • 选做：开源可用但频率或依赖度略低，学完必做后按需深入
  • 了解为主：以商业产品为主、无成熟开源方案 → 原则上不做实验，只通过文档/演示/试用理解
  • 商业产品实验策略：除非网上有破解/学习版（仅限个人学习环境），否则不做商业实验；有破解/学习版就优先用破解版实操。Cobalt Strike 收费，优先用开源 Sliver 学习，有 CS 学习版再做对照
