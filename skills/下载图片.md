# Skill: 下载图片

> 职责：批量下载文章中的远程图片到本地 `assets/` 目录。

## 输入

- 图片 URL 列表
- 目标目录（如 `src/like/assets/`、`src/ai/assets/`、`src/perm/assets/`）

## 输出

- 所有图片保存到指定目录
- 返回图片文件名列表，供后续路径替换使用

## 操作步骤

1. 从文章 Markdown 中提取所有远程图片 URL
2. 为每张图片生成文件名（保留原文件名或按 `image-时间戳-随机串.png` 命名）
3. 一次性运行 PowerShell 脚本批量下载：

```powershell
# 在 C:\blog 根目录运行
$urls = @(
    @{url="图片URL1";name="图片名1.png"},
    @{url="图片URL2";name="图片名2.png"}
)
$outDir = "C:\blog\src\like\assets"  # 根据目标目录调整
foreach ($item in $urls) {
    Invoke-WebRequest -Uri $item.url -OutFile (Join-Path $outDir $item.name)
}
```

## 注意事项

- 一次性批量下载，不要逐个下载，节省 Token
- 图片保存到对应目录的 `assets/` 子目录
- 若图片 URL 失效或需鉴权，提示用户手动提供图片
