# Skill: 推送 GitHub

> 职责：将新增或修改的文章提交并推送到 GitHub 远程仓库。

## 输入

- 提交信息（如"add: 新增文章标题"）

## 输出

- 代码已提交并推送到 `origin` 远程仓库

## 操作步骤

```bash
git add . && git commit -m "add: 新增文章标题" && git push
```

## 提交信息规范

| 操作类型 | 格式 | 示例 |
|----------|------|------|
| 新增文章 | `add: 文章标题` | `add: 新增XX漏洞分析文章` |
| 更新文章 | `update: 文章标题` | `update: 更新XX靶机实战内容` |
| 删除文章 | `del: 文章标题` | `del: 移除过时文章` |
| 配置变更 | `config: 变更说明` | `config: 更新导航栏配置` |

## 注意事项

- 使用 `git add .` 一次性添加所有变更，不要逐个指定文件
- 提交信息使用中文，简洁明了
- 推送失败时检查网络或远程仓库配置
