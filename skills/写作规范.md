# Skill: 写作规范

> 职责：规定文章写作的风格、结构与发布纪律。

## 写作定位

- 以**博主第一人称**讲解实验过程，语气自然、实战导向
- 生成的是**实验框架和步骤**，不是百科全书式的内容堆砌
- 文章需**图文并茂**：博主在实验过程中粘贴截图到预留位置，才算完成

## 文章结构规范

1. **开头**：简述实验目的与背景（1-2 段）
2. **环境准备**：表格列出实验环境（角色/系统/IP）
3. **实验步骤**：分步骤讲解，每步包含：
   - 操作说明（博主口吻）
   - 命令/配置代码块
   - **截图占位符**：`![描述](./assets/图片名.png)`，博主后续替换
4. **总结**：实验收获与注意事项
5. **法律声明**：渗透测试类文章需包含授权提醒

## 截图占位规范

在需要截图的位置预留占位符，格式：

```markdown
![步骤描述](./assets/占位-步骤名.png)
```

博主实验时将实际截图替换占位符，图片保存到对应目录的 `assets/` 下。

## 发布纪律

::: danger 重要
- **生成的文章不能直接推送 GitHub**
- 只有当用户明确说"推送"时，才执行 `git add && git commit && git push`
- 生成文章后，告知用户文章已就绪，等待用户补充截图和推送指令
:::
