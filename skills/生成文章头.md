# Skill: 生成文章头

> 职责：根据文章元信息生成 VuePress frontmatter 文件头。

## 输入

- 标题（必填）
- 短标题（可选，默认取标题前若干字）
- 日期（可选，默认当前时间）
- 描述（可选）
- 标签（可选）
- 分类（必填，决定目标目录）
- 是否原创（可选，默认 false）

## 输出

- 符合项目规范的 YAML frontmatter 块

## 模板

### 转载文章（`src/like/`）

```yaml
---
title: '标题'
short_title: '短标题'
date: YYYY-MM-DD HH:MM:SS
description: 描述
tag:
  - 标签
category:
  - 转载
timeline: false
isOriginal: false
index: true
---
```

### AI 对话笔记（`src/ai/`）

```yaml
---
title: '标题'
short_title: '短标题'
date: YYYY-MM-DD HH:MM:SS
description: 描述
tag:
  - 标签
category:
  - AI对话笔记
timeline: false
isOriginal: false
index: true
---
```

### 原创文章（`src/perm/`、`src/response/` 等）

```yaml
---
title: '标题'
short_title: '短标题'
date: YYYY-MM-DD HH:MM:SS
description: 描述
tag:
  - 标签
category:
  - 渗透测试
timeline: false
isOriginal: true
index: true
---
```

## 分类与目录对照

| category | 目标目录 | isOriginal |
|----------|----------|------------|
| 转载 | `src/like/` | false |
| AI对话笔记 | `src/ai/` | false |
| 渗透测试 | `src/perm/` | true |
| 应急响应 | `src/response/` | true |
| 逆向工程 | `src/reverse/` | true |
| 计网基础 / 编程开发 / 网络运维 | `src/net/` | true |

## 注意事项

- `date` 格式：`YYYY-MM-DD HH:MM:SS`
- `timeline` 默认 false，时间轴类文章设为 true
- `index` 默认 true，不需要被搜索索引的文章设为 false
