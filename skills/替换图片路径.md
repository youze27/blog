# Skill: 替换图片路径

> 职责：将文章 Markdown 中的远程图片 URL 批量替换为本地相对路径。

## 输入

- 文章 Markdown 内容
- 图片 URL 与本地文件名的映射关系（来自"下载图片"Skill 的输出）

## 输出

- 所有远程图片 URL 替换为 `./assets/xxx.png` 格式的本地路径

## 操作步骤

1. 获取"下载图片"Skill 返回的 URL → 文件名映射
2. 使用单一正则表达式或批量替换，将所有远程 URL 替换为本地路径
3. 替换格式：`./assets/文件名.png`

## 示例

替换前：
```markdown
![图片](https://example.com/images/2024/screenshot.png)
```

替换后：
```markdown
![图片](./assets/image-20240814145025-sgd99ls.png)
```

## 注意事项

- 使用批量替换，不要逐个 `edit`，节省 Token
- 本地路径统一用 `./assets/xxx.png` 相对路径格式
- 确保所有远程 URL 都被替换，无遗漏
