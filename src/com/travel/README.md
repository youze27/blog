跋山涉水，并非为了征服远方，而是为了在世界的褶皱里，找回那个走失的自己。每一帧影像，都不是地标的复刻，而是灵魂与山河的一次密谈。我不记录风景，我只打捞那些被日常淹没的、诗意的浮光掠影。

Crossing mountains and rivers is not to conquer distant places, but to find the lost self in the folds of the world. Every image is not a replica of a landmark, but a secret talk between the soul and the mountains and rivers. I don't record the scenery, I only salvage those poetic glimpses that are submerged by daily life.
